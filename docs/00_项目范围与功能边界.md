# 农业秸秆焚烧区域火点检测与分析平台 — 项目范围与功能边界

> 当前交付依据：原仓库 \`feature/regional-ui-consolidation-v1\` 重构分支的实际 Windows 桌面程序。早期规划已由本文件替换。对外正式功能以最终实机验收版本为准。

## 1. 产品定位

本软件面向农业相关区域的 FIRMS 火点观测分析。用户将实际取得的 NASA FIRMS 主动火点 CSV 导入 Windows 桌面程序，软件按本次任务整理观测记录，提供时间分布、真实空间位置、农业地表背景、跨日期变化、可用的历史与天气信息，并支持保存任务和导出 Word 图文报告。

软件优先将原始指标转化为可定位、可查看的结果：哪里最集中、哪天观测最多、哪些位置在不同日期重复出现，以及已匹配观测的土地覆盖分类。所有结果与任务实际数据对应。

## 2. 当前正式业务输入

- **必选：** NASA FIRMS CSV，支持一个或多个文件，字段校验和有效观测整理。
- **选填：** 当前任务的区域名称（只作为用户标签）及经纬度筛选矩形（西、南、东、北）。
- **高级可选：** 来源明确、合规可安装的 GeoJSON 区域边界，用于精确边界模式与离线地图轮廓。
- **上下文资料：** 实际可覆盖当前点位的 MCD12Q1 2024 土地覆盖栅格、有来源的农事时段 JSON 规则、具有可比性的 FIRMS 历史资料、实际获取的 NASA POWER / NOAA GFS 天气资料。

普通 CSV 分析不要求预装行政区边界；也不把数据标签当作已确认行政区归属。辅助资料的缺失不会自动阻止有效 CSV 的时空统计。

## 3. 当前结果能力

1. **观测概览：** 有效观测数量、日期范围、活跃天数及按日趋势。
2. **空间地图：** Canvas 真实点位、拖动、连续缩放、按日期/网格定位，离线轮廓数据可选安装。
3. **时空重点：** 实际 0.25° 热点网格、当日高值位置、约 5 km 跨日重复网格及前三网格对照。
4. **农业相关性：** 对真实匹配的 MCD12Q1 观测采样，呈现耕地/混合植被与其他地表类别及实际分类像元邻域。农事时段规则按已配置的数据执行。
5. **历史和天气：** 可比历史同期差异；NASA POWER 历史天气及 NOAA GFS 近期 24/48/72 小时气象信息。
6. **记录与导出：** SQLite 本地分析记录、结果重开与重命名、Word DOCX 图文报告及其统计图表。

## 4. 结果使用口径

有效观测条数指主动火点记录，不直接等同于独立火灾次数。土地覆盖统计仅反映已匹配的观测位置，不能代表整个区域面积；跨日重复统计反映网格与日期上的重复记录，不直接认定某一火源持续燃烧。天气和历史背景与当前任务实际取得的时空数据对应。

软件不凭空生成火灾发生概率、火灾原因归属或官方火险等级。

## 5. 交付与验收范围

软件仅作为 Windows 桌面 EXE 交付，完整发布包采用 PyInstaller onedir 结构。页面用于本地桌面窗口呈现，开发调试用的浏览器界面不作为单独 Web 产品。主仓库和原重构分支内维护代码，不创建并行替代项目。

代码测试、EXE 本体自检与 ZIP 完整性验证已纳入发布流程；实际窗口交互、旧数据保留和 Word 排版必须在 Windows 实机中逐项确认。材料入口参见 [软件使用说明候选稿](SOFTWARE_MANUAL_V1_DRAFT.md)、[登记信息采集表候选稿](SOFTWARE_REGISTRATION_FORM_DRAFT.md)和[交付验收手册](DELIVERY_HANDOFF.md)。
