# 可配置分析区域：第一阶段（只读预览）

此分支尚未改变正式分析的区域、地图和报告输出口径，不能视为全国范围完整支持。

新增 POST /api/region-preview：上传标准 FIRMS CSV（files）和可选 GeoJSON（boundary_file），返回可用边界内各候选地区的观测记录数量及匹配/未匹配数量。

未指定 GeoJSON 时使用当前数据库已有的区域边界；如果这些边界未覆盖所提交数据，则返回空候选，并提示导入相应边界。上传的 GeoJSON 只在本次请求中参与比对，不写入数据库。

文件限额：单个 CSV 32 MB；GeoJSON 16 MB；总计至多读取 250000 条有效或无效记录。GeoJSON 需要 FeatureCollection、有效 Polygon/MultiPolygon、WGS84 经纬度、区域 name 字段。此阶段尚未实现 ZIP Shapefile、全国省市县边界加载、用户确认区域后正式分析以及地图自动缩放。

正式 V1.0 主分支保持不变。下一阶段应先获取来源、许可明确的行政区边界，新增按任务保存的范围与边界版本，再改写火点落区、地图与报告逻辑。不可简单替换全局数据库中的边界，否则旧任务将失去可追溯性。
