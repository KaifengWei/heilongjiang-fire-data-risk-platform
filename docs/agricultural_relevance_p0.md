# 农业秸秆焚烧相关性 P0 —— 数据依据与配置

软件正式名称：**农业秸秆焚烧火点遥感检测与风险分析平台**。

本模块分析的是遥感热异常与农业秸秆焚烧活动的**相关性线索**，不自动确认秸秆燃烧事实；与既有火点活动风险关注等级分别计算、分别展示。

## 输入与判别口径

1. **FIRMS CSV**：提取时间、位置、卫星观测质量及 FRP。置信度和 FRP 可作为观测线索，但不能证明具体燃料来源，本版不将 FRP 直接累加到秸秆类型等级中。
2. **MCD12Q1 2024 LC_Type1**：IGBP 12 表示耕地、14 表示耕地与自然植被混合区。只有落在实际栅格覆盖范围内的点才获得有效地表背景；无数据或超出覆盖范围，统一记录为“证据不足”。现有配套栅格是有限区域的数据文件，**不是全国完整土地覆盖栅格**。
3. **当地农事时段**：由用户根据有权使用的农业资料提供“地区名称、作物、关联月份、来源”。软件不自造全国统一收获日期，未配置地区不能按其月份推断秸秆处理时期。

| 空间背景 | 农事时段 | 相关性 |
|---|---|---|
| IGBP 12 耕地 | 匹配当地配置月份 | 较高相关 |
| IGBP 14 耕地混合 | 匹配当地配置月份 | 可能相关 |
| IGBP 12 耕地 | 无规则 | 可能相关（仅空间线索） |
| IGBP 14 耕地混合 | 无规则 | 证据不足 |
| 耕地/混合区 | 不在已配置月份内 | 较低相关 |
| 其他类型 | 任意 | 较低相关 |
| 无有效土地覆盖值 | 任意 | 证据不足 |

“较高相关”**仍不是确认发生秸秆焚烧**。500米级栅格及卫星主动火点像元不能用来确定确切地块或燃烧物质。

## 一次性配置农事规则

开始分析页面底部展开“农事时段规则”，选择 JSON 文件并点击“安装农事规则”。软件将配置持久保存在桌面应用的运行数据目录下，随后创建的新分析任务会将所用规则**快照保存到任务 parameters**，避免改动配置后旧任务结果发生漂移。

农事 JSON 结构如下（仅为**程序格式示例**，月份不是事实依据，不建议作为真实分析直接安装）：

```json
{
  "schema_version": 1,
  "rules": [
    {
      "region_name": "演示区域",
      "crop": "演示作物",
      "months": [10, 11],
      "source": "仅用于软件功能测试，请在实际应用中替换为有出处的地区农事资料"
    }
  ]
}
```

地区名称应与“本次分析区域”中的名称完全一致；不匹配时该地区视为“尚无农事时段”。月份数组只表达用户提供的相关月份，**不能单独说明真实秸秆焚烧发生**。

## 仍需完成的工作

- 获取与实际分析区域匹配、来源明确的土地覆盖栅格，避免对未覆盖地区得出错误类别。
- 对实际要申报/演示的区域，收集具体农事时历及来源、验证时段对应关系。
- 视数据基础增加燃烧迹地佐证属于后续 P1，不应在说明书中声称 P0 已实现影像烧痕自动核验。
