# 离线地理底图（GeoJSON）

当前分析地图始终使用 FIRMS CSV 的真实经纬度绘制观测点。原有内置地区边界只能覆盖其实际数据范围；不将旧省域边界冒充全国底图。

## 使用方法

1. 选择公开来源清楚、具有使用权限的面状地理数据。若原数据不是 WGS84 经纬度坐标，应先在 GIS 软件中转换成 EPSG:4326；用来源数据直接转换，不能靠修改文件名代替坐标变换。
2. 在 GIS 软件中保留所需的真实面边界，必要时轻量简化并导出 GeoJSON。单文件最大 12 MB、至多 350 个面要素，处理后最大 4 MB。
3. 在软件“分析结果 → 观测点分布”展开“导入离线地图（GeoJSON）”，选择文件，填写来源并确认使用权限。安装到软件本地运行目录，之后可离线使用。
4. 结果页优先按本次火点坐标显示，支持切换“查看轮廓全貌”。所有火点位置、筛选、区域声明和 Word 报告均不因底图安装而改变。

## 底图数据依据

官方基础地理信息数据参考：全国地理信息资源目录服务系统的 **1:100万公众版基础地理信息数据（2021）**；该页面说明涵盖全国陆地、主要岛屿和邻近海域，属于分幅矢量数据，正式地图表达需依规定处理，网址：https://www.webmap.cn/commres.do?method=result100W 。

地图合规参考：自然资源部标准地图服务 https://bzdt.ch.mnr.gov.cn/ 。原始 GIS 数据与经过审核的最终地图不是同一个产品；软件内可将用户拥有权限的 GeoJSON 用于本地分析背景，但公开展示、分发或出版前须核实相应规范与审核要求。

**当前版本不声称已经内置全国底图。** 用户没有安装对应区域的真实数据时继续显示经纬度网格，不自动下载在线地图，不绘制虚构的国界或行政区轮廓。

安装后的离线底图保存至当前 Windows 用户的 `%LOCALAPPDATA%\\AgriculturalFirmsAnalysis\\map_background\\reference_basemap.json`，不放在 `dist` 打包输出目录；重新打包 EXE 不会清除该文件。测试环境使用测试数据库所在目录隔离数据。
