# 中国境内可配置分析区域：边界来源与安装口径

## 当前功能范围

本项目以标准 NASA FIRMS CSV 的经纬度开展落区识别。每次上传创建一条分析任务，所有成功匹配到所安装边界的地区均参与同一任务；地图右侧的地区筛选只调整展示范围，不会重新生成任务。

“可配置分析区域”不等于“已经安装全国所有省市县边界”。系统只对真实配置且通过校验的边界做空间匹配。未匹配观测须明确提示，不使用外接矩形或近似地图轮廓冒充行政边界。

## 用户补充边界（现在可用）

在“开始分析 → 高级设置”里选 GeoJSON（WGS84，经纬度 EPSG:4326），填写具体数据来源，并确认具有使用权限，然后点击“将边界保存到本地库”。软件将保存来源描述和源文件 SHA-256 校验值；下次启动仍可直接识别这些地区，不必再次导入同一边界。

- 文件必须是 FeatureCollection，Feature 的 properties.name 必须填写，geometry 必须是有效 Polygon 或 MultiPolygon。
- 同一个文件内、文件与已配置边界之间，不允许地区重名或有面积重叠。相邻区域共享边界线是正常情况。
- 当前目录以互不重叠的同级范围为对象；省市县嵌套数据不能直接混合导入，否则观测可能重复计数。
- 单文件最多 16 MB、4000 个区域。安装信息保存在本地 SQLite，不替换旧表、旧任务或原始 CSV。
- 本软件只能核对用户填写的来源和使用权限确认，不能自动证明上传文件满足公开地图规范。

## 候选公开数据来源（尚未自动打包）

geoBoundaries 的 gbOpen 数据以 CC BY 4.0 为主要开放许可框架，需要保留适当的来源署名及数据版本。可通过官方元数据接口查验：

- 省级候选：https://www.geoboundaries.org/api/current/gbOpen/CHN/ADM1/
- 下一级候选：https://www.geoboundaries.org/api/current/gbOpen/CHN/ADM2/
- API 许可：https://www.geoboundaries.org/api.html

**不能直接认定这套候选数据可作为正式公开地图使用。** 当前元数据中的 ADM1 代表年份为 2019、ADM2 为 2017，名称口径和分级并不一定与本软件原有市县层级一致。实际安装前须核对更新日期、精度、覆盖、中文地名映射、授权和国内公开地图规范；尤其不能把 ADM2 不经检查就称作“市级”。

可查阅《地图管理条例》和《公开地图内容表示规范》（自然资规〔2023〕2号）。用于面向公众发布的行政界线地图应采用符合相关要求的版本。现阶段不把来源、图式或有效性未经核实的全国边界强行写入正式 EXE。

## 后续收尾

1. 获取并核验符合使用要求的统一中国境内行政区边界数据，统一行政层级、名称及区域编号；
2. 将全国省级定位和市县下钻设计为独立层次，避免跨层级多边形直接混合造成重复统计；
3. 复核历史同期、土地覆盖、天气背景对当前分析区域的适用范围，不适用时标记暂无对应数据；
4. 以完整的 Windows 环境回归结果为依据重新打包 EXE，校验导入、地图、分析记录和 Word 报告，再同步撰写最终软著说明书。
