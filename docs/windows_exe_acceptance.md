# Windows EXE 打包与验收（方案 B）

适用分支：`feature/regional-ui-consolidation-v1`。正式产品名称：**农业秸秆焚烧区域火点检测与分析平台**。

## 打包前

首页右侧使用已经确认的地球遥感 WebP 封面。源代码仓库**未包含**该图片，请使用此前已确定、授权且真实存在的文件，放到 `static/images/home_earth_orbit.webp`。缺失、过小或格式不符时，PyInstaller 构建将直接报错，避免发布残缺的 EXE。请勿用随机占位图替代用户已选定的视觉资源。

先在 Windows 的项目目录中激活既有 `fire-monitor` Conda 环境，关闭正在运行的旧 EXE，再执行：

```powershell
conda activate fire-monitor
powershell -ExecutionPolicy Bypass -File ".\scripts\build_and_check_exe.ps1" -CoverSource "D:\实际路径\home_earth_orbit.webp"
```

若图片已经在 `static/images` 下，则省略 `-CoverSource`。脚本执行 Python 全量测试、JavaScript 语法检查（有 Node.js 时）、PyInstaller 打包，并通过 `scripts/verify_windows_bundle.py` 核查首页图片、页面模板、地图静态资源、GDAL/PROJ/GEOS 运行组件。任一必需文件缺失即终止交付。

原有分析记录、CSV 和地图继续使用 Windows 用户数据目录 `%LOCALAPPDATA%\HeilongjiangFireMonitor`。数据库位于 `runtime\fire_monitor.sqlite`，上传文件位于 `uploads`，地图位于 `runtime\map_background\reference_basemap.json`。重新打包只更新项目中的 `dist`；**不要清理用户数据目录**。

- [ ] 旧分析记录能够重新打开；关闭并再次启动 EXE 后，历史记录仍在

## 验收原则

CI 的 pytest / JavaScript 成功仅证明代码层回归检查通过；Windows GUI、数据目录持久化、下载路径和运行组件必须通过以上实测。不要删除 `dist` 文件夹中的依赖文件后单独分发 EXE。

正式提交软著材料前，依据实际实测结果、截图和 Word 报告修订说明书；`main` 分支继续保留稳定版本。

## 地图交互检查

- [ ] 新导入的用户声明区域记录：普通鼠标滚轮仍滚动页面，鼠标位于地图上时 **Ctrl + 滚轮** 以指针为中心连续放大或缩小
- [ ] 地图上拖动可平移视角，省界、火点和经纬度网格保持一致，右下角显示悬停坐标
- [ ] 使用地图工具栏的 **+ / −** 按钮同样可以缩放；点击“查看底图全貌／返回观测范围”会恢复相应预设视图
- [ ] 旧精确行政区记录保持原来的市县交互，地图操作不会修改 FIRMS 筛选、任务数据库或 Word 报告结果

## Word 空间证据收口（新 CSV）

- [ ] Word 报告地图上的刻度与正文经纬度范围一致；最高观测量的 0.25° 网格在图中标为橙色矩形
- [ ] “重点观测位置与日期”列出前五个真实网格中心、数量、比例、涉及日期及高值日；高值日与本任务 CSV 的 acquired_date 对应
- [ ] 地区名称仅来自实际安装的 GeoJSON 空间匹配；没有覆盖时显示真实经纬度，不虚构地名
- [ ] 报告的区域统计基于全部任务观测，地图至多抽样绘制 5000 个点；重复观测被数据库复用时总数不变
- [ ] Word 中图表编号连续；修改记录名称、缩放网页地图不会改变已保存的 FIRMS 原始观测和报告统计

## 跨日期空间线索与农业相关性检查

- [ ] 前五个 0.25° 网格的农事相关性数量与本任务相同网格的逐条判别一致，不借用其他任务/地区的评级
- [ ] 同网格跨两日出现观测时显示“跨日期重复观测”；同日多条观测不能误写为跨日期
- [ ] 农事规则或土地覆盖不可用时，网格评级仍为证据不足，不把重复活跃等同于秸秆焚烧事实
- [ ] 约 5 km 持续活跃网格与 0.25° 报告网格分别保留既有口径，不合并计算数量

## 面向使用者的 Word 核查建议

- [ ] Word 重点网格表每行明确给出经纬度范围、观测日期与数量、实际核查动作，不出现“可能相关 X / 证据不足 Y”的分类数字拼盘
- [ ] 有真实耕地栅格匹配时，建议检查相应田块与田间作业记录；没有匹配时建议先看卫星影像确认地表类型
- [ ] 同网格跨日期时建议逐日比对点位；单日多个观测不能描述为持续燃烧或重复起火
- [ ] 网格只是空间定位单元，不作为地块边界；Word 的建议依据本次 CSV 的时间及位置，而非任何模型预测概率
- [ ] 农业相关性原有四类数据可在结果页内部保留供审查，导出报告以可执行核查事项为主

## Word A4 分页与去重复验收

- [ ] 报告统一为 A4 纵向、中文宋体及西文 Times New Roman；新 CSV 首页四项摘要为观测数、观测日期范围、峰值日期和有火点日期，不用“暂无历史同期判断”占用位置
- [ ] “本次重点”在正文前部直接给出最应查看的真实经纬度网格、对应观测数量及高值日，后文不再重复同一段行动建议
- [ ] 地图与“图1”图注留在同一页；没有 GeoJSON 时不描述不存在的蓝色行政区轮廓
- [ ] 三列核查清单的表头跨页重复，任何一行“坐标／依据／行动”不得被截成两页
- [ ] 图像、地图标识、网格数据与导出任务一致；分页合格与否须通过 Windows Word 实际打开确认，不能仅凭 DOCX 结构测试判定
