# 风险评级方法与口径（V1.0 需求基线）

## 1. 为什么不能仅凭“火点多”直接写成“高风险”

FIRMS 给出的是卫星主动火点观测，MCD64A1 给出的是火烧迹地产品。二者能够描述火情活动和影响范围，但完整的灾害风险通常还涉及承灾体、暴露度、脆弱性、气象条件和管理目标。

因此，V1.0 把评级分成两个模式：

1. **遥感火情相对关注等级**：仅使用主动火点和火烧迹地数据，用于同一批次内比较哪些区域更值得关注；
2. **规则型风险等级**：只有加载经用户单位确认的阈值、权重和适用范围后才输出，平台负责执行规则，不声称规则来自官方。

没有规则文件或比较样本时，平台只输出统计结果，不生成“高、中、低风险”。

## 2. 核心可计算指标

### 2.1 主动火点观测密度

```text
主动火点观测密度 = 质量筛选后的主动火点观测记录数 ÷ 区域面积 × 1,000
单位：条 / 1,000 km²
```

采用密度而不是总数，避免哈尔滨等大区域因面积较大天然拥有更多记录。

### 2.2 火烧迹地面积比例

```text
火烧迹地面积比例 = 火烧迹地面积估算值 ÷ 区域面积 × 100%
```

同一栅格像元若因相邻行政区边界重叠而命中多个区域，省级合计必须去重；逐市统计应执行唯一归属规则并记录边界版本。

### 2.3 FRP 密度（可选）

```text
FRP 密度 = 有效 FRP 总和 ÷ 区域面积 × 1,000
单位：MW / 1,000 km²
```

FRP 是火辐射功率，不是面积。缺失 FRP 的记录不能填成 0 后参与平均；应统计有效样本数并在报告中说明。

### 2.4 高质量观测比例（可选）

```text
高质量观测比例 = 高置信度记录数 ÷ 有有效置信度的记录数
```

MODIS 和 VIIRS 的置信度编码不同，应先按传感器分别解释，再汇总为统一质量类别。

### 2.5 时间集中或变化指标（可选）

在选定基准期明确、日期完整时，可计算：

```text
近期占比 = 最近 N 天主动火点记录数 ÷ 全时段主动火点记录数
环比变化 = (本期指标 - 基准期指标) ÷ 基准期指标
```

当基准期为 0、日期缺失或产品尚未完成标准处理时，平台应显示“不具备可比条件”，不能用无限大或任意替代值评级。

## 3. 模式 A：遥感火情相对关注等级

适用条件：同一时间段、同一数据源/质量规则下至少有多个行政区或多个规则网格可比较。

建议流程：

1. 计算主动火点观测密度和火烧迹地面积比例；
2. 对每个指标在本批次内做百分位排名；
3. 以配置文件指定的组合方式形成相对得分；
4. 按分位数或自然断点重分类为 1–5 级；
5. 输出“本批次相对关注等级”，并写明比较范围、时间和数据源。

平台不得把默认组合权重隐藏在代码中。即使采用等权，也必须在任务参数和报告里展示。若只有一个城市且没有网格化比较单元，不输出相对等级。

推荐名称：

| 级别 | 页面名称 |
|---:|---|
| 1 | 低关注 |
| 2 | 较低关注 |
| 3 | 中等关注 |
| 4 | 较高关注 |
| 5 | 高关注 |

这些名称表示同批次内的相对排序，不是官方火灾预警颜色或应急响应级别。

## 4. 模式 B：规则型风险等级

适用条件：用户或项目管理单位提供正式规则文件，至少明确：

- 规则名称、版本和制定单位；
- 适用区域、季节和数据源；
- 每个指标的分级阈值；
- 指标权重或组合逻辑；
- 缺失值处理方式；
- 最终得分到等级的映射；
- 生效日期和审核人。

一般执行形式：

```text
指标重分类得分 si ∈ {1,2,3,4,5}
综合得分 S = Σ(wi × si) ÷ Σ(wi)
最终等级 = 按规则文件给定的 S 阈值重分类
```

公式本身只是执行框架，`wi`、指标阈值和最终等级阈值不得由开发者凭经验填写。每次输出必须写入规则文件 SHA-256，保证结果可追溯。

## 5. 综合风险的增强数据

若未来要从“遥感火情关注”升级为更完整的“综合风险”，应增加并分别验证：

| 数据 | 用途 | 没有时的处理 |
|---|---|---|
| 耕地/作物分布栅格 | 判断火烧迹地是否落在农田，形成疑似农田火烧范围 | 不作秸秆焚烧归因 |
| 气象数据 | 风速、降水、干燥程度等危险性指标 | 不输出气象驱动风险 |
| 居民地、道路、保护区等承灾体 | 暴露度与邻近性分析 | 只输出遥感火情等级 |
| 历史多年基线 | 判断异常程度和季节性 | 不输出历史异常等级 |
| 地面核查或执法记录 | 精度评价和模型校准 | 不声称地面准确率 |

不同来源的这些数据需要独立的数据许可、字段合同、坐标系处理和质量说明，不能在 V1.0 中用虚构示例替代真实输入。

## 6. 评级输出必须包含的解释

每条评级结果至少包含：

- 区域、时间范围和区域面积；
- 主动火点数据源、传感器、处理级别和质量规则；
- 火烧迹地产品名称、版本、QA 是否提供；
- 原始指标值、重分类得分、权重和综合得分；
- 评级模式（相对关注/规则型风险）；
- 比较集合或规则文件版本与哈希；
- 数据缺失、处理警告和适用限制。

只有这些信息完整，风险等级才是可重复、可讨论、可审计的分析结果。
